# Real-Time Video Capture & Processing on FPGA

A hardware video pipeline written in **Verilog** for the **Digilent Basys 3 (Artix-7)**. It configures an **OV7670** camera over SCCB, captures frames into on-chip memory, applies real-time image filters, and outputs live video to a **VGA** monitor.

Final project for *Hardware Synthesis Lab I*.

## Features
- Automatic camera initialization over **SCCB** (I²C-like protocol), written from scratch
- Pixel capture from the OV7670 (RGB444) into a 320×240 **true dual-port block-RAM frame buffer**, which also crosses the camera clock domain (PCLK) into the VGA clock domain
- **640×480 VGA output** at a 25 MHz pixel clock generated by an MMCM
- **7 real-time filters**, selected with the board's slide switches:

| SW[2:0] | Mode |
|:---:|---|
| `000` | Raw video |
| `001` | Color inversion (negative) |
| `010` | Red channel isolation |
| `011` | Green channel isolation |
| `100` | Blue channel isolation |
| `101` | Grayscale |
| `110` | Threshold (binary black & white) |

The filter block is purely combinational, so each pixel is processed without adding frame latency. Grayscale and thresholding use an integer approximation of luminance: `Y ≈ (5R + 9G + 2B) >> 4`.

## Architecture
```
OV7670 ──► ov7670_capture ──► frame_buffer (BRAM) ──► image_filter ──► vga_display ──► VGA monitor
   ▲                                                       ▲
   └── ov7670_init + sccb_master (camera config)           └── SW[2:0]
```

| Module | Role |
|---|---|
| `top.v` | Top-level wiring |
| `clk_wiz.v` | MMCM clocking: 24 MHz camera XCLK, 25 MHz VGA pixel clock |
| `sccb_master.v` / `ov7670_init.v` | Camera register configuration over SCCB |
| `ov7670_capture.v` | Converts the camera's byte stream into pixels |
| `frame_buffer.v` | 320×240 RGB444 true dual-port BRAM (camera writes, VGA reads) |
| `image_filter.v` | Switch-selectable filters |
| `vga_sync.v` / `vga_display.v` | VGA timing and pixel output |

## Verification
Each core module has a testbench in [`sim/`](sim): `tb_sccb_master`, `tb_ov7670_capture`, `tb_image_filter`, `tb_vga_sync`, and a full-system `tb_top`.

## Hardware
- Digilent Basys 3 (xc7a35tcpg236-1)
- OV7670 camera module (non-FIFO), wired to PMOD headers JB/JC
- VGA monitor

Pin mapping, setup and operating instructions are in [MANUAL.md](MANUAL.md). Debugging notes are in [FPGA_Video_Processing_Debug_Report.md](FPGA_Video_Processing_Debug_Report.md).

## Build
1. Open `Final_Project.xpr` in **Xilinx Vivado**
2. Run Synthesis → Implementation → Generate Bitstream
3. Program the Basys 3 from Hardware Manager
